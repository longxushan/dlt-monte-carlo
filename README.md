# 大乐透-龙须山快选

单文件网页应用，用于大乐透统计分析与参考选号。内置真实开奖数据（体彩官方接口），打开页面自动更新最新期号。

## 在线使用

https://longxushan.github.io/dlt-monte-carlo/

## 功能

- **概览**：热冷号 Top 排名、最近 10 期开奖
- **选号生成**：单式(5+2)、复式、胆拖三种玩法，实时计算注数与金额，一键复制
- **自动生成器**：多策略批量生成号码 + 一键复制

## 本地使用

直接双击打开 `index.html` 即可（Chart.js 已本地化，无需联网）。
